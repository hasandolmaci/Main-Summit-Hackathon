Build a prior-anchored logistic-regression benchmark. Python with numpy, scipy, scikit-learn (installed). Read DATA_README.md, prior_weights.json, data_dictionary.csv, backtest.csv and prompts/design_astra.md. Finish within ~15 minutes; prefer working code over completeness.

FINAL DESIGN (follow exactly):
- Labels: y_label (1/0; blank = excluded). Sensitivity: y_label_incl_dead.
- Learned features (7): f_pricing_page, f_impressum, f_customer_logos, f_jobs_page, age_le_18 (= f_age_months <= 18; unknown if f_age_months blank), m_grant_score, has_legal_entity (= f_legal_entity non-empty and not '0'). Missing handling: one indicator snapshot_missing (f_* features blank -> value 0 + indicator 1); separate indicator age_missing. All other prior features (GitHub, patents, Product Hunt, serial, external score, etc.) keep their prior weight frozen and are included only through the prior score.
- Year control: year-band dummies band_2022_23, band_2024_25 (base 2019-21), unpenalised-ish (penalty 0.5). New startups are scored as band 2024-25 but the band is NOT part of displayed merit.
- Prior score S_prior = sum(prior_weight_j * x_j) over all prior features present in prior_weights.json (missing = 0), computed exactly as prior_weights.json says.
- Model: logit(p) = a + gamma*band + k*S_prior + X*delta + M*eta, where delta are adjustments for the 7 learned features (so final weight_j = k*w_prior_j + delta_j), eta for missing indicators. Fit with scipy.optimize (L-BFGS) minimising logloss + lam*(||delta||^2 + ||eta||^2) + 0.5*||gamma||^2; intercept unpenalised. Choose k from grid [1,2,4,8] and lam from grid [1,4,16,64] by repeated stratified 5-fold CV (20 repeats) on mean log loss.
- Baselines in CV: constant (prevalence), year-only logistic, prior-offset (a + gamma + k*S_prior, no deltas), full model. Report AUC, Brier, log loss mean +/- sd across repeats, and 1000-sample bootstrap 95% CI for out-of-fold AUC of full vs prior-offset.
- Stability: 1000 bootstrap refits with chosen k/lam: median, 2.5-97.5% interval, share positive for each final weight.
- Sensitivity: rerun CV for y_label_incl_dead.
- Benchmark mapping: Quality group = m_grant_score, m_gh_has_open_source, m_gh_external_score, m_patent_verified_before_asof, m_ph_score_before_asof, f_customer_logos (+ any other prior quality features present); Opportunity group = f_pricing_page, f_impressum, has_legal_entity, f_gmbh_ig, f_waitlist, f_jobs_page, age_le_18. Contribution_j = final_weight_j * x_j. quality_raw, opportunity_raw, total_raw = sums. Convert each to 0-100 percentile against the frozen reference = all 205 backtest rows (tie-aware). Also coverage % = share of model features observed. No probabilities displayed.
- Eligibility gates in scoring: if a column y_funding_status/cb_has_equity_round indicates funded, or info flags say not German, or any gate column provided says fail -> status INELIGIBLE with reason; if unknown -> REVIEW; else ELIGIBLE. For new startups without those columns, status = ELIGIBLE_UNCHECKED.
