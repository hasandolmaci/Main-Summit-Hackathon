GOAL: Collect scoring metrics for 20 NEW live German startup leads and produce a scorer-ready CSV. Working dir = backtest-data. Python stdlib only (as in CONTRACT.md). Polite scraping, cache under raw/cache/<script>/. GITHUB_TOKEN is in the environment (never print or write it).

INPUT: raw/cohort_linkedin_live.csv (columns name,website,description,source,cohort,asof_date; asof_date = 2026-11-21 = today, so 'before as-of' means current public data).

FILES YOU MAY CREATE/MODIFY (ONLY THESE): raw/features_cohort_linkedin_live.csv, raw/evidence_cohort_linkedin_live.csv, raw/live_metrics.csv, live_leads.csv, scripts/live_metrics.py, codex_LIVE_notes.md, and cache dirs. Do NOT modify any other file (not backtest.csv, not existing scripts, not models/). Existing scripts may be imported or run with their CLI if their outputs go to new files only; read their source first and if a script would overwrite an existing file, copy its logic into scripts/live_metrics.py instead.

STEPS:
1. Run: python -X utf8 scripts/features.py raw/cohort_linkedin_live.csv --workers 5  (writes raw/features_cohort_linkedin_live.csv). This gives f_* website features (impressum, legal entity, GmbH i.G., pricing, waitlist, customer logos, jobs page, age, certs, product_live, description text).
2. Write scripts/live_metrics.py that, for each of the 20 companies, collects into raw/live_metrics.csv (blank = unknown, never guess):
   - GitHub: find the company org (search by name/domain, verify the org's blog/website matches the domain). m_gh_has_open_source (1 if public non-fork repos with commits), m_gh_external_score (0-1, contributions by org members to outside repos if cheaply derivable, else blank), m_gh_commit_weeks_active_8w.
   - Funding check (gate 'not funded'): search free news/web (e.g. DuckDuckGo html, startbase.de, deutsche-startups.de, eu-startups, the company site press page) for 'Finanzierung', 'Seed', 'raises', 'Investment', 'pre-seed', investor names. Columns: funding_status in {NONE_FOUND, ANGEL_SMALL, INSTITUTIONAL, UNKNOWN}, funding_evidence_url, funding_note. INSTITUTIONAL = VC/CVC round, YC/top accelerator equity, or round > EUR 150k.
   - Grants/programmes: mentions of EXIST, SPRIND, EIC, BMBF, Horizon, Gründungsstipendium, incubators/accelerators on site or news -> m_grant_score (1 grant found, 0.5 programme/incubator only, 0 searched none) + evidence url.
   - Founders: from the Impressum/legal page, Geschäftsführer names (names only; no emails, no private data) -> s_founder_names, founder_count. If cheaply findable via the site's team/about page: founder_technical (1 if a founder has PhD/engineering/CS background stated), founder_serial (1 if site/news says previously founded a company). Else blank.
   - Product Hunt: check producthunt.com/products/<slug> guesses or search; m_ph_score (1 top3 day, .66 top10, .33 launched, 0 none found).
   - Patents/trademarks: optional, only if a free quick lookup works (DPMA register is hard; skip if blocked) -> blank otherwise.
   - Sector guess: one of software/ai, hardware/deeptech, health, energy/climate, other, plus is_consulting_or_agency (1 if site mainly sells services/consulting).
3. Build live_leads.csv in the EXACT column schema of backtest.csv (copy header from backtest.csv). Fill: id_company (slug), id_domain, id_name, meta_cohort_source=linkedin_apify, meta_cohort, meta_asof_date (format DD/MM/YYYY like backtest.csv), meta_sampling=live, all f_* columns that exist in backtest.csv from the features file, m_gh_has_open_source, m_gh_external_score, m_grant_score, m_ph_score_before_asof (=m_ph_score), m_serial_score (=founder_serial), m_founder_technical, s_founder_names where those columns exist. Map funding: y_funding_status = FUNDED_BEFORE if INSTITUTIONAL else NO_FUNDING_FOUND if NONE_FOUND/ANGEL_SMALL else UNKNOWN. Leave all y_label columns blank. Check every column you fill actually exists in backtest.csv header; print which metrics could not be mapped.
4. Validate: 20 rows, header identical to backtest.csv, print per-column fill counts for the filled metrics.
5. Write codex_LIVE_notes.md: per company one line (name | funding_status + evidence | founders | github | grants | PH | sector | consulting?) and a coverage summary. Be honest about blanks.
Budget: aim to finish in ~25 minutes; if a source is slow/blocked, skip it and leave blanks.
